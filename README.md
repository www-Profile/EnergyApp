# EnergyApp

Мобильное веб-приложение с демонстрационной историей за 30 дней.

## Запуск на компьютере

Распакуй весь архив в одну папку и открой `index.html` в браузере. Графики и иконки входят в комплект. Для запуска не нужны установка пакетов, сборка или интернет.

## Запуск на телефоне

Папку приложения можно разместить на любом статическом хостинге, в том числе на GitHub Pages. Для публикации в корне репозитория положи туда содержимое папки EnergyApp так, чтобы `index.html` лежал рядом со `styles.css`, `data.js`, `app.js`, `icon.svg` и папкой `vendor`. После публикации открой адрес сайта в Safari или Chrome.

## Как устроены файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка трёх экранов, карточки, подписи, кнопки и навигация |
| `styles.css` | Мобильная и широкая компоновки, тёмные темы и анимации |
| `data.js` | Демодни, условный расчёт энергии, рекомендации и сохранение состояния |
| `app.js` | Экраны, графики, навигация, формы профиля и настроек |
| `icon.svg` | Иконка EnergyApp |
| `vendor/` | Chart.js и тексты лицензий используемых компонентов |

## Как менять интерфейс

Открой `index.html` в редакторе кода. Комментарии «ЭНЕРГИЯ», «СТАТИСТИКА» и «ПРОФИЛЬ» отмечают начало экранов. Можно менять надписи внутри тегов и переставлять карточки целиком. Сохраняй атрибуты `id` и `data-…` — по ним JavaScript находит элементы для кнопок, чисел и графиков. Цвета и размеры находятся в `styles.css`.

## Демоданные

При первом запуске приложение создаёт историю за последние 30 местных календарных дней. При смене даты окно сдвигается. Данные пересекающихся дат сохраняются. Для сравнения с прошлым периодом нужны два полных периода. На вкладке «Год» точки показывают среднее по доступным дням каждого месяца.

Цели влияют на подписи карточек и рекомендации. Профиль и настройки хранятся в текущем браузере в LocalStorage. При запрете записи изменения действуют до закрытия страницы. Уведомления отображаются внутри приложения. Все показатели, включая фазы сна и почасовую динамику энергии, демонстрационные.
